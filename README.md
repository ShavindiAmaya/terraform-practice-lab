# Terraform AWS EC2 Practice Lab

This project demonstrates how Terraform can be used to provision and destroy an AWS EC2 instance.

## Technologies
- Terraform
- AWS
- EC2

## Commands
```bash
terraform init
terraform validate
terraform plan
terraform apply
terraform destroy
```

## Workflow
1. Configure the AWS provider.
2. Create an EC2 instance using Terraform.
3. Initialize the project with `terraform init`.
4. Validate the configuration.
5. Review changes using `terraform plan`.
6. Provision the instance using `terraform apply`.
7. Verify the instance in AWS EC2.
8. Remove the resources using `terraform destroy`.

## Security
Do not commit AWS access keys or secret keys to this repository.
